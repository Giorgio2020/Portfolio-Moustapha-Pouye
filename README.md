# Moustapha Pouye — Portfolio & CV

Site vitrine professionnel en français, responsive (ordinateur, tablette et mobile), réalisé en HTML, CSS et JavaScript.

## Contenu
- `index.html` : page principale (profil, expertises, parcours, réalisations, contact)
- `assets/css/style.css` : styles et mise en page
- `assets/js/main.js` : interactions et filtres de la galerie
- `assets/cv-moustapha-pouye.pdf` : CV PDF téléchargeable
- `assets/portfolio/` : 39 visuels exportés du portfolio original fourni, organisés par catégorie :
  - Identité visuelle (10)
  - Visuels de communication (14)
  - Visuels réseaux sociaux (11)
  - Magazine (4)

## Utilisation
1. Décompresser l'archive ZIP.
2. Ouvrir `index.html` dans un navigateur.
3. Une connexion Internet est nécessaire uniquement pour charger les polices Google Fonts. Le reste du site et les visuels fonctionnent localement.

Les cartes de la galerie ouvrent le visuel en grand dans un nouvel onglet. Les boutons permettent de filtrer les réalisations par catégorie.

## Publication
Le dossier peut être déployé sur GitHub Pages, Netlify ou tout hébergement statique. Conserver la structure des dossiers lors de l'envoi.
